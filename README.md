# SalaryPAGE

**A modern job platform built to make job searching simpler, faster, and more personalized.**

SalaryPAGE is a job-search platform focused on creating a cleaner and more useful experience for candidates. It helps users discover relevant job opportunities, explore listings, build their professional profile, and manage their job search from one place.

## ✨ Features

* 🔎 **Job Discovery** — Browse and explore relevant job opportunities.
* 🎯 **Job Recommendations** — Get job suggestions based on your profile and preferences.
* 👤 **Candidate Profiles** — Create and maintain a professional job-seeker profile.
* 📄 **Profile & Resume Information** — Organize important career and professional details.
* 🏢 **Recruiter Experience** — Designed with both candidates and employers in mind.
* 🎨 **Modern UI/UX** — Clean, responsive, and focused on making job searching easier.
* 🔐 **Authentication** — Secure user authentication and account management.
* 📱 **Responsive Design** — Built to work across desktop and mobile screen sizes.

## 🛠️ Tech Stack

* **Frontend:** Next.js, React, TypeScript
* **Styling:** CSS
* **Backend & Database:** Supabase
* **Authentication:** Supabase Auth
* **Testing:** Playwright
* **Package Manager:** npm

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

* Node.js
* npm
* Git

### Installation

Clone the repository:

```bash
git clone https://github.com/Aayushman669/SalaryPAGE.git
```

Navigate to the project:

```bash
cd SalaryPAGE
```

Install dependencies:

```bash
npm install
```

### Environment Variables

Create a `.env.local` file in the project root and add the required environment variables.

**Never commit your `.env.local` file or expose your private credentials.**

### Run the Development Server

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```
